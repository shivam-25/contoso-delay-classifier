| 🧭 Approach (2–4 lines) | Loaded the 10k-row CSV into Azure SQL behind a `vw_DelayTraining` view so features and analysis can't drift, and answered the three questions as **rates**, not counts: IndiaPost is 2.2× worse than BlueDart (28.6% vs 13.2%), a sale day almost exactly doubles delays (32.1% vs 16.2%), and backlog is a monotonic gradient (15.2% → 26.8%). Trained LogisticRegression vs HistGradientBoosting and shipped the **lower-accuracy** model deliberately: at 18.1% positives, HistGB scores 81.8% accuracy while catching only 17% of real delays, so LogReg wins where it matters (AUC 0.743, recall 0.673, F1 0.451). The model serves as JSON weights inside a Node Functions v4 API — verified identical to scikit-learn to 0.0 — with every request, including 400s, logged to Cosmos `requests` and surfaced live as p50/p95 and error rate. |
